
# Pandas Analyzer & Data Visualization

**Author:** Mahendra Patel

## About Project

This is my Python project based on Pandas, NumPy,
Matplotlib and Seaborn.

It is used to analyze sales data and create different
charts for better understanding of data.

## Features

1. Load sales data from CSV file.
2. Explore and clean data.
3. Convert data into NumPy arrays.
4. Perform mathematical operations.
5. Combine and split data.
6. Search, sort and filter data.
7. Calculate sum, mean, minimum and maximum.
8. Perform statistical analysis.
9. Create pivot tables.
10. Generate different charts and graphs.

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn

## Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn
```

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run this command:

```bash
python pandas_analyzer.py
```

4. Select options from the main menu.

## Files Created

- sales_data.csv - Stores sales records.
- sales_chart.png - Stores generated charts.

Both files are created automatically by the program.
